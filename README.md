Netflix Exploratory Data Analysis (EDA) 📊
This repository contains a comprehensive Exploratory Data Analysis (EDA) of the Netflix Titles dataset. The goal of this project is to uncover insights into the types of content available on the platform and prepare the data for future machine learning applications.

🚀 Key Features
Data Cleaning: Handled missing values in director, cast, and country columns.

Statistical Analysis: Generated descriptive statistics to understand data distribution.

Visualizations: Created insightful plots using Seaborn and Matplotlib, including:

Content Type Distribution (Movies vs. TV Shows).

Correlation matrices for numerical features.

Machine Learning Preparation: Implemented a train_test_split to prepare the dataset for classification models.

🛠️ Technologies Used
Python

Pandas (Data Manipulation)

NumPy (Numerical Analysis)

Seaborn & Matplotlib (Data Visualization)

Scikit-learn (Preprocessing)

📂 Project Structure
EDA.ipynb: The main Jupyter Notebook containing the analysis and code.

netflix_titles.csv: The raw dataset used for analysis.

📈 Summary of Insights
The analysis reveals the current balance between Movies and TV Shows on Netflix, identifies the primary countries producing content, and cleans the data to ensure high-quality inputs for predictive modeling.
